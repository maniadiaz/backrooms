# Recursos y dependencias

Las texturas, modelos, sonidos sintetizados, código y documentación de Bedroom forman parte de este proyecto. Los generadores de recursos están en `scripts/`; los sonidos propios no utilizan grabaciones ni voces de terceros.

Minecraft Java Edition, Forge, Java y Essential son productos/dependencias externos con sus propias condiciones. No se incluyen sus instaladores, binarios, cuentas ni bibliotecas en los ZIP de Bedroom. Algunos bloques/modelos y sonidos se referencian desde Minecraft en tiempo de ejecución; no se copian sus recursos a los paquetes.

El proyecto conserva `All Rights Reserved`, tal como figura en `mods.toml`. Esta entrega no cambia la licencia del propietario ni concede una licencia nueva sobre productos de terceros.
